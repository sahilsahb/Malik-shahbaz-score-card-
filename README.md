# Malik Shahbaz Score Card V2

Independent Android application project for `v2-development`.

## Current starter features
- Native Android app using Kotlin and Jetpack Compose
- V2 branding and blue/gold visual direction
- New match setup: T20, ODI, Test, team names, overs and toss/batting-first choice
- Live innings score, over counter, runs, wides, no-balls, byes, leg-byes and wickets
- Undo last delivery
- Basic innings transition and match history screen
- Offline-first; no account or network permission required

## Build
Open this folder in Android Studio (Hedgehog or newer), allow Gradle sync, then choose **Build > Build APK(s)**.

The original logo has not yet been supplied; a temporary cricket icon is used. Replace it with the original logo and create launcher assets when the logo file is provided.

## Important
This is an initial V2 source foundation, not a tested/released APK. Match persistence, full batting/bowling scorecard, player editing, result calculation, share/export and automated tests remain to be implemented and tested.
